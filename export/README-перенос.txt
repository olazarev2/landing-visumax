ПЕРЕНОС СТРАНИЦЫ VISUMAX НА mikof.md — комплект готов
=======================================================

Файлы блоков (вставлять в поле Body через кнопку «Источник»):
  visumax-ru-body.html   -> страница mikof.md/ru/visumax
  visumax-en-body.html   -> страница mikof.md/en/visumax
  visumax-ro-body.html   -> страница mikof.md/visumax

В каждом блоке УЖЕ вшито: весь CSS, весь JS (карусель + FAQ без Bootstrap),
абсолютные ссылки на картинки (с Vercel). Грузить картинки на сервер НЕ нужно.

------------------------------------------------------------
ПОШАГОВО (начни с RU, проверь, потом en/ro):

1. Создай новую страницу в нужном языковом разделе админки.

2. Поле "Alias":  visumax

3. Поле "Meta title":
   RU: SMILE Pro на VisuMax 800 — лазерная коррекция зрения | MIKOF
   EN: SMILE Pro on VisuMax 800 — laser vision correction | MIKOF
   RO: SMILE Pro pe VisuMax 800 — corecție laser a vederii | MIKOF

4. Поле "Meta description":
   RU: Лазерная коррекция зрения по методике SMILE Pro на оборудовании ZEISS VisuMax 800 в клинике MIKOF.
   EN: Laser vision correction with the SMILE Pro method on ZEISS VisuMax 800 equipment at the MIKOF clinic.
   RO: Corecția laser a vederii prin metoda SMILE Pro pe echipamentul ZEISS VisuMax 800 la clinica MIKOF.

5. Поле "Body":
   - нажми кнопку «Источник» (значок </> слева вверху редактора);
   - открой файл visumax-<язык>-body.html в Блокноте;
   - выдели всё (Ctrl+A), скопируй (Ctrl+C);
   - вставь в поле Body (Ctrl+V);
   - ВАЖНО: НЕ нажимай «Источник» обратно (не переключайся в визуальный режим) —
     иначе редактор поломает вёрстку карусели. Сразу сохраняй.

6. Сохрани (зелёная кнопка внизу).

7. Открой страницу и проверь:
   - листается ли карусель (стрелки/точки), есть ли автопрокрутка;
   - раскрывается ли FAQ по клику;
   - видны ли все фото;
   - порядок прайса: слева Диагностика 700 MDL, справа SmilePro 23000 MDL.

------------------------------------------------------------
ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ:

- Карусель/FAQ статичны, не реагируют на клик  -> CMS вырезала <script> при
  сохранении. Решение: попросить разработчика mikof.md подключить наш JS в
  шаблон, ИЛИ разрешить <script> в этом поле.
- Слетела вёрстка (всё в столбик, нет стилей) -> CMS вырезала <style>.
  Аналогично: вынести CSS в файл и подключить в шаблоне.
- Не видно картинок -> сайт блокирует внешние изображения (CSP). Тогда залить
  картинки в медиа mikof.md и заменить домен ссылок.
