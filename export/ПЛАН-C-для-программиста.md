# План C — подключить интерактивную карусель на странице /visumax (инструкция для разработчика mikof.md)

## TL;DR
Нужно подключить **один JS-файл в шаблон сайта** (перед `</body>`). Скрипт — чистый ванильный JS (~4 КБ), без зависимостей, активируется только на странице с каруселью, на остальных страницах не делает ничего. CSP сайта подключение уже разрешает.

---

## Контекст и причина
- Страница: **https://mikof.md/visumax.shtml** (позже также `/ru/visumax`, `/en/visumax`).
- Контент страницы залит через админку (поле **Body** визуального редактора).
- На странице есть карусель «Путь пациента по дням» (блок с `id="journeyTrack"`).
- **Проблема:** CMS **вырезает любые `<script>` из поля Body** — проверено: удаляются и инлайн-скрипты, и внешние `<script src="…">` (в т.ч. с jsDelivr). В DOM итоговой страницы тега скрипта нет.
- **Вывод:** JS карусели нельзя подключить из контента. Он должен жить в **шаблоне сайта** (футер/layout), где скрипты не вырезаются.

Сейчас карусель работает в «облегчённом» режиме на чистом CSS (свайп на мобиле + полоса прокрутки на десктопе). Скрипт включит полноценный режим: **стрелки ‹ ›, точки-индикаторы, плавное листание без «прыжка» страницы, перетаскивание мышью, автопрокрутку.**

---

## Что нужно сделать — 1 строка в шаблон

Добавить подключение скрипта в общий шаблон сайта, **перед закрывающим `</body>`** (туда же, где обычно подключаются глобальные скрипты футера).

### Вариант 1 — self-host (рекомендуется)
Положить файл `visumax-carousel.js` на сервер mikof.md (например, в `/assets/js/`) и подключить:
```html
<script src="/assets/js/visumax-carousel.js" defer></script>
```
Исходник файла:
- репозиторий: `https://github.com/olazarev2/landing-visumax/blob/main/visumax-carousel.js`
- прямая ссылка (raw / можно скачать): `https://cdn.jsdelivr.net/gh/olazarev2/landing-visumax@main/visumax-carousel.js`

### Вариант 2 — через CDN jsDelivr (без заливки файла на сервер)
```html
<script src="https://cdn.jsdelivr.net/gh/olazarev2/landing-visumax@main/visumax-carousel.js" defer></script>
```

> Рекомендация: **self-host** — нет зависимости от внешнего CDN, грузится с того же домена. Но оба варианта рабочие, CSP разрешает оба.

---

## Это безопасно для всего сайта
- Скрипт в самом начале проверяет наличие элемента `#journeyTrack`. **Если его нет — мгновенный выход, ноль влияния.** Этот элемент есть только на странице /visumax, поэтому на остальных страницах скрипт не делает ничего.
- Не трогает глобальные объекты, не вешает глобальных обработчиков на document/body (только на свой блок карусели).
- Без зависимостей (не требует jQuery/Bootstrap), ~4 КБ, ванильный JS.
- Идемпотентен: повторная инициализация защищена флагом (`dataset.vmInit`).
- Уважает `prefers-reduced-motion` (при включённом — без автопрокрутки и анимаций).

Поэтому его можно спокойно подключать **глобально** в футер-шаблон.

---

## CSP — уже разрешено (донастройка не нужна)
Текущий заголовок `Content-Security-Policy` сайта содержит:
```
script-src 'self' 'unsafe-inline' 'unsafe-eval' … https://*.jsdelivr.net …
```
То есть проходят **оба** варианта:
- `'self'` → self-host (`/assets/js/visumax-carousel.js`);
- `https://*.jsdelivr.net` → вариант с CDN.

Дополнительно править CSP не требуется.

---

## Как проверить, что заработало
1. Открыть `https://mikof.md/visumax.shtml`, обновить с Ctrl+F5.
2. У карусели «Путь пациента» появятся **стрелки ‹ ›** и **точки-индикаторы** внизу.
3. Клик по стрелке/точке → слайд листается **плавно, страница НЕ прыгает**.
4. Навести курсор на карусель — автопрокрутка ставится на паузу.
5. Открыть любую **другую** страницу сайта — никаких изменений (скрипт там не активируется).

В консоли браузера не должно быть ошибок, связанных со скриптом.

---

## Что от автора контента (не от разработчика)
- Сам HTML/CSS контента страницы и финальную подгонку скрипта под итоговую вёрстку обеспечивает автор лендинга (Олег). К моменту внедрения будет предоставлена финальная версия `visumax-carousel.js`.
- **Задача разработчика — только подключить файл в шаблон** (1 строка выше) и подтвердить, что CSP/шаблон это пропускают.
